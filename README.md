# diegoaleyvag.github.io

Solo redirecciones al portafolio actual, https://diegoleyva.dev. Cada ruta antigua devuelve una página con `refresh` y `canonical` a su destino exacto.

- Las páginas se generan con `scripts/make-redirects.mjs`.
- `downloads/cv/diego-leyva-cv.pdf` es una copia del CV publicado; se actualiza en cada publicación del CV.
- El sitio anterior quedó archivado en el repo privado `portfolio-v1-archivo`.
